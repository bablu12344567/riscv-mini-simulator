# RISC-V Mini Simulator

## 📌 Project Description
A simple C++ based simulator that demonstrates basic RISC-V register operations.

## 🚀 Features
- 8 Register simulation (x0 – x7)
- ADD instruction support
- Simple instruction execution
- Displays final register state

## 🛠️ Technologies Used
- C++
- g++
- MSYS2
- Git

## ▶️ How To Run

Compile:
g++ main.cpp -o sim

Run:
./sim
